# Student Management System – CLI

A Python-based command-line Student Management System built to practice and apply core Python programming concepts. It allows users to add, display, search, and delete student records through a simple menu-driven interface.

## Features

- Add students
- Display students
- Search students
- Delete students
- Student result calculation
- Lists and dictionaries
- Functions and modules
- JSON file storage
- Exception handling

## Technologies

Python • JSON • Functions • Modules • File Handling • Exception Handling
